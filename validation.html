How the check works

Ten children were drawn at random (fixed seed) from the reference group for each level of the aorta. For each child, R computed two z-scores: one from the full model (height, weight for height, age and sex) and one from the height-and-sex model used when weight is missing. Those R values come from the exported tables, which were themselves checked against the gamlss fit to within 0.0001.

This page loads the same tables, recomputes all of those z-scores with the calculator's own code, and compares them. A difference under 0.001 counts as a match. The largest difference is on the order of 0.0001, from interpolating between table points and from rounding the R values to four decimals. Model tables dated —.

Lauzon-Schnittka implementation

The comparison table also shows Lauzon-Schnittka z-scores. To check that implementation, the authors' own Excel calculator was recalculated (in LibreOffice) for 20 children across ages, builds and both sexes, and those values are compared here with the browser.
